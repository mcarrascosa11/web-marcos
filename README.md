# marcoscarrascosa.com

Web de Marcos Carrascosa, arquitecto.

## Publicar un proyecto

Pásale a Claude:

1. Las fotos originales, a la máxima resolución que tengas (la portada, mejor de 3000 px o más).
2. Cuál es la foto de portada y, si quieres, el plano.
3. El texto del proyecto y la ficha: lugar, fecha, estado, superficie, promotor, PEM, constructora, equipo, fotografía.
4. Si debe salir en el carrusel de la página de inicio.

Claude prepara las fotos, escribe la ficha y lo publica. Las instrucciones técnicas están en [CLAUDE.md](CLAUDE.md).

## Dónde está cada cosa

- `contenido/`: textos, fotos y datos de la web.
- `src/`: diseño y código.
